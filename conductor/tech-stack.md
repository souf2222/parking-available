# Tech Stack

## Programming Language
The primary programming language for this project will be JavaScript/TypeScript, offering a robust and scalable solution for both frontend and backend development.

## Frontend Framework
React will be utilized as the frontend framework. Its component-based architecture and extensive ecosystem are well-suited for building interactive and dynamic user interfaces, especially for the calendar view and status update functionalities.

## Backend Framework
Node.js with Express.js will form the foundation of the backend. This choice provides a lightweight and flexible framework for handling API requests, managing data, and serving the web application efficiently.

## Database
SQLite will be used as the database. Given the small scale of the application and the hosting environment (Unraid server), SQLite offers a simple, file-based database solution that is easy to set up and manage without the need for a separate database server.

## Deployment
Deployment to the Unraid server will leverage Docker containers. This approach ensures consistent environments, simplifies the deployment process, and provides excellent portability and scalability for the application.
